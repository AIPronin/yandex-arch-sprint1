# Спринт 1
## Задание 1
### Уровень 1. Проектирование
**Задача:** Выберите фреймворк для создания микрофронтендов и опишите решение в удобном вам виде.

**Варианты решения:** 
1. Webpack Module Federation
2. Single SPA

**Анализ:**

Используя стратегию проектирования *Вертикальная нарезка* выделяем следующие микрофронтенды:
1. Авторизация и регистрация - отвечает за следующие функции:
   1. Регистрация - регистрация пользователя на сайте 
   2. Авторизация - авторизация пользователя на сайте
   3. Аутентификация - аутентификация пользователя на сайте
   4. Логаут - выход пользователя с сайта
2. Пользователь - отвечает за следующие функции:
   1. Профиль пользователя - вывод данных пользователя 
   2. Редактирование профиля пользователя - редактирование данных пользователя
   3. Редактировать аватар - редактирование аватара пользователя
3. Места - отвечает за следующие функции:
   1. Список мест - выводит список мест
   2. Просмотр места - выводит информацию о конкретном месте
   3. Добавить место - пользователь добавляет новое место
   4. Удалить место - удалить место, которое опубликовал пользователь
   5. Лайк карточки - Выводит лайки для мест. Возможность поставить, убрать лайк с карточки.

> Webpack Module Federation позволяет микрофронтендам динамически обмениваться зависимостями во время выполнения. Вы сможете использовать разные версии библиотек без конфликтов. 
> Single SPA делает упор на бесшовной интеграции и разнообразии фреймворков. 
> И то, и другое решение поддерживает функцию lazy loading.

Текущее приложение использует один фреймворк React. 
В качестве фреймворка для создания микрофронтендов планирую использовать Webpack Module Federation.



### Уровень 2. Планирование изменений
**Задача:** Предоставьте структуру кода и обоснуйте своё решение в Readme.md. Вы можете создать необходимые проекты, добавить в них подкаталоги для контролов и логики, разложить код исходного проекта по ним, но запускать проекты не нужно.

**Решение:**
Были выделены следующие микрофронтенды из исходного решения:
1. host-microfrontend - основной микрофронтенд, отвечающий за инициализацию приложения и основные элементы.
2. auth-microfrontend - микрофронтенд, отвечающий за функционал регистрации, авторизации, аутентификации и выхода.
3. profile-microfrontend - микрофронтенд, отвечающий за вывод и изменение профиля пользователя
4. places-microfrontend - микрофронтенд, отвечающий за вывод и добавление/удаление мест

**Структура проекта:**
```
/frontend/microfrontend
   /auth-microfrontend - микрофронтенд авторизации и регистрации
      /src
         /blocks
            /auth-form - стили для формы авторизации и регистрации
            /login - стили для компонента входа
         /components
            Login.js - компонент  авторизации
            Register.js - компонент регистрации
         /utils
            auth.js - утилиты для работы с API авторизации, аутентификации и регистрации 
         index.js - точка входа в микрофронтенд
         index.css - подключение стилей для отображения микрофронтенда 
      package.json - описание зависимостей микрофронтенда
      webpack.config.js - настройка webpack микрофронтенда
      
   /host-microfrontend - Микрофронтенд хост
      /src
         /blocks
            /content - стили для блока вывода контента
            /footer - стили для футера
            /header - стили для хедера
            /page - стили для основной страницы
            /popup - стили для попап окна
         /components
            App.js - компонент приложения
            Footer.js - компонент футера
            Header.js - компонент хедера
            InfoTooltip.js - компонент тултипа 
            Main.js - компонент основной страницы приложения
            PopupWithForm.js - компонент попапа с формой
            ProtectedRoute.js - компонент защищенных редиректов
         /contexts
            CurrentUserContext.js - реализация контекста 
         /images - иконки и изображения
         /utils
            api.js - утилиты для работы с backend API
         /vendor - базовые стили
         index.js - точка входа в микрофронтенд
         index.css - подключение стилей для отображения микрофронтенда 
         logo.svg - логотип

   /places-microfrontend - микрофронтенд места
      /src
         /blocks - стили для мест
            /card - стили для вывода места
            /places - стили для списка мест
         /components
            AddPlacePopup.js - компонент  добавления нового места
            Card.js - компонент вывода места
            ImagePopup.js - компонент просмотра информации о месте
         index.js - точка входа в микрофронтенд
         index.css - подключение стилей для отображения микрофронтенда 
      package.json - описание зависимостей микрофронтенда
      webpack.config.js - настройка webpack микрофронтенда

         /blocks
            /profile - стили для профиля пользователя
         /components
```
